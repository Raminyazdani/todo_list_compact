# محدودهٔ فعلی با دستور مستقیم مالک

در ۱۴ اکتبر ۲۰۲۶ مالک سه تغییر را خواست: استفاده از Neon، کنارگذاشتن موقت AI داخل برنامه، و دسترسی همین دستیار Codex از طریق MCP. این دستور بر الزامات قدیمی AI زنده، اعتبار مدل و نصب اتصال در ChatGPT مقدم است. شواهد قبلی مهاجرت، گراف و بازیابی همچنان تاریخی و معتبرند؛ برای این تغییر دوباره اجرا نمی‌شوند.

دیتابیس دائمی از قبل روی PostgreSQL در Neon است. فضای فایل جدید و پشتیبان رمزنگاری‌شده برای Neon Object Storage پیاده می‌شوند. ارجاع‌های اصلی Google Drive و فایل‌های قبلی Blob provider خود را حفظ می‌کنند. اعتبارنامهٔ S3 فقط روی سرور می‌ماند؛ endpoint برنامه دانلود را پس از کنترل مالکیت انجام می‌دهد. فعال‌سازی PUT به بررسی واقعی عدم بازنویسی object وابسته است؛ آزمون مصنوعی SDK جای این شاهد را نمی‌گیرد.

AI داخل برنامه فعلاً خاموش است: لینک، فرم و widget آن نمایش داده نمی‌شوند و endpointهای AI پس از احراز هویت درخواست را با FEATURE_DISABLED رد می‌کنند. MCP مستقل است و محدودیت scope، revision، idempotency و audit دامنه را حفظ می‌کند.

رمز خواسته‌شده روی حساب موجود تنظیم شد. ورود واقعی HTTPS موفق و نشست‌های قبلی لغو شدند. خود رمز در این سند، Git یا گزارش عمومی ثبت نمی‌شود. فرم و سرور تنظیم رمز، حداقل هشت کاراکتر را می‌پذیرند.

اتصال `life_os` در تنظیمات محلی Codex ثبت شد و login بومی OAuth موفق بود. scopeهای معمول کار، پروژه، فایل، تقویم، ساعت کار و Activity اعطا شدند؛ admin و backup در این اتصال نیستند. این شاهد هنوز به معنی بارگذاری ابزار در چت جاری نیست: runtime همین چت، سرور تازه را نشناخت. بازکردن دوبارهٔ همین چت برای بارگذاری ابزار و سپس یک خواندن واقعی MCP لازم است.

فعال‌سازی فضای فایل منتظر ورود مالک به حساب موجود Neon است. CLI نصب است اما profile احراز‌شده ندارد. مالک `neon login` را محلی اجرا می‌کند؛ کلید یا رمز را در چت نمی‌فرستد. پس از آن، همان پروژه و branch تولید باید از endpoint فعلی تأیید شود، bucket خصوصی و credential محدود ساخته شود، آزمایش واقعی conditional PUT و دانلود بی‌مجوز انجام شود و محیط سرور تنظیم گردد. هیچ پروژهٔ جایگزین، خرید یا تغییر منبع اصلی برای دورزدن این مرحله مجاز نیست.

نتیجهٔ آزمون‌ها و انتشار همین تغییر در [BUILD_PROGRESS.json](BUILD_PROGRESS.json) ثبت می‌شود. تا تکمیل شاهد زندهٔ Neon و بارگذاری واقعی ابزار MCP، این دو بخش تحویل کامل اعلام نمی‌شوند. اتصال تقویم خارجی و ثبت passkey/PWA همچنان مراحل جداگانهٔ مالک‌اند.
