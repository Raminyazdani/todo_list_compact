# محدودهٔ فعلی با دستور مستقیم مالک

در ۱۴ اکتبر ۲۰۲۶ مالک سه تغییر را خواست: استفاده از Neon، کنارگذاشتن موقت AI داخل برنامه، و دسترسی همین دستیار Codex از طریق MCP. این دستور بر الزامات قدیمی AI زنده، اعتبار مدل و نصب اتصال در ChatGPT مقدم است. شواهد قبلی مهاجرت، گراف و بازیابی همچنان تاریخی و معتبرند؛ برای این تغییر دوباره اجرا نمی‌شوند.

دیتابیس دائمی از قبل روی PostgreSQL در Neon است. فضای فایل Neon اکنون در تولید فعال است. پس از ورود مالک، پروژه و branch موجود با endpoint هر دیتابیس تطبیق داده شدند و bucket خصوصی و credential محدود جدا برای staging و تولید ساخته شد. conditional PUT واقعی در هر دو محیط بازنویسی را با 412 رد کرد و دریافت بی‌مجوز هم رد شد. CHECK افزایشی قبلی فایل‌های موجود را تغییر نداده بود؛ اکنون بارگذاری دو نسخه، دانلود دقیق، پیش‌نمایش و مقایسهٔ متن در UI واقعی تولید هم موفق است. ارجاع‌های اصلی Google Drive و فایل‌های قبلی Blob provider خود را حفظ می‌کنند. اعتبارنامهٔ S3 فقط روی سرور می‌ماند و دانلود برنامه کنترل مالکیت دارد. [شاهد زندهٔ Neon](NEON_LIVE_VERIFICATION.md) جزئیات و مرز شواهد پشتیبان را ثبت می‌کند.

AI داخل برنامه فعلاً خاموش است: لینک، فرم و widget آن نمایش داده نمی‌شوند و endpointهای AI پس از احراز هویت درخواست را با FEATURE_DISABLED رد می‌کنند. ورود از فرم واقعی سایت، صفحهٔ غیرفعال AI، API آن، تنظیمات MCP و حداقل رمز هشت‌کاراکتری روی نسخهٔ منتشرشده تأیید شد؛ هر سه فایل اصلی بدون ورود401/noRedirect بودند و هیچ write تجاری در این بررسی انجام نشد. MCP مستقل است و محدودیت scope، revision، idempotency و audit دامنه را حفظ می‌کند.

رمز خواسته‌شده روی حساب موجود تنظیم شد. ورود واقعی HTTPS موفق و نشست‌های قبلی لغو شدند. خود رمز در این سند، Git یا گزارش عمومی ثبت نمی‌شود. فرم و سرور تنظیم رمز، حداقل هشت کاراکتر را می‌پذیرند.

اتصال بومی life_os اکنون در همین چت بارگذاری شده و پنج خواندن واقعی MCP موفق بودند: whoami با حساب موجود و کانال MCP، capabilities، health، جست‌وجوی کار و فایل. ۱۳۰ ابزار، ۱۲ scope معمول بدون admin/backup، ۴۵ کار فعال و سه فایل اصلی تأیید شدند. اتصال Neon سالم، پشتیبان verified و AI غیرفعال است. این بررسی هیچ write تجاری انجام نداد. مشکل اولیهٔ unknown server تاریخی است؛ پس از refresh اتصال، ابزارها واقعاً در runtime همین چت ظاهر و فراخوانی شدند.

ورود مالک به Neon انجام شد و تنظیمات سرور با gate واقعی فعال شدند. نسخهٔ تولید با محیط تازه READY شد؛ کد runtime همان نسخهٔ کامل آزموده‌شده است. ۹ عملیات canonical و ۹ audit متناظر، retry همان upload، دو نسخه و چهار رد دانلود بی‌مجوز بررسی شدند. یک کار و دو فایل ساختگی از همان journal آرشیو شدند؛ ۴۵ کار و سه فایل اصلی فعال و تمام ردیف‌های قبلی بررسی‌شده بدون تغییر ماندند. ورود، ساخت bucket/credential، import، restore یا تغییر رمز را دوباره اجرا نکن. هیچ خرید، ارتقای پلن، پروژهٔ جایگزین یا تغییر DATABASE_URL انجام نشده است.

نسخهٔ نهایی d347404 با [CI 38574338435](https://github.com/Raminyazdani/todo_list_compact/actions/runs/38574338435) کامل موفق و deployment تولید READY است: ۴۶۲ آزمون coverage، ۱۲ PostgreSQL واقعی، ۲۴ مرورگر، کاتالوگ ۱۳۰ ابزار MCP و همهٔ آزمون‌های HTTP/OIDC/rate-limit/انقضای واقعی توکن پاس شدند. ۲۸ opt-in و سه سناریوی مرورگر skip صریح دارند. نتیجهٔ دقیق در [BUILD_PROGRESS.json](BUILD_PROGRESS.json) است. شاهد زندهٔ فایل Neon و خواندن واقعی ابزار MCP همین چت اکنون موفق‌اند. تغییرهای مستقیم خواسته‌شدهٔ مالک تکمیل شده‌اند؛ اجرای زمان‌بندی‌شدهٔ cron هنوز مشاهده نشده است. اتصال تقویم خارجی و ثبت passkey/PWA همچنان مراحل جداگانهٔ مالک‌اند.
