# Security boundaries and observed evidence

This model describes implemented controls and remaining verification work. A unit test, mock provider or local smoke does not prove a production connection. Source Google data, private backups, resource mappings and credentials remain outside public Git.

| Boundary                                 | Concrete threat                                                                | Control and evidence                                                                                                                                                                                                                             | Remaining gate                                                        |
| ---------------------------------------- | ------------------------------------------------------------------------------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ | --------------------------------------------------------------------- |
| Public browser to private owner data     | Unauthenticated task/file disclosure, guessed IDs                              | Owner allowlist, server session/token checks, owner-scoped SQL; actual local HTTP public API/file/MCP requests deny access                                                                                                                       | Production unauthenticated and indexing checks NOT_RUN                |
| Cookie session to mutations              | Cross-site request forgery, stale/revoked session                              | Exact Origin check for cookie writes; secure provider session handling; actual local hostile-Origin denial; independent cookie/bearer downgrade policy tests                                                                                     | Production cookie flags/origin tests NOT_RUN                          |
| OAuth/MCP client to canonical commands   | Forged/expired JWT, wrong audience, read-only grant writes, unsafe redirect    | Provider PKCE/consent, issuer/audience/JWKS validation, owner identity and active-session check, domain scopes; actual PKCE read-only REST/MCP denial, forged/unsigned tokens denied, issued-token expiry denied, redirect/signup negative tests | Public HTTPS remote client and ChatGPT installation NOT_RUN           |
| Concurrent writers to task DAG/hierarchy | Opposite-edge race, cycles, stale revision, partial batch                      | Per-owner SQL transaction/advisory lock, database triggers, FK/uniqueness, pinned previews/revisions and idempotency; separate real multi-connection staging and synthetic graph tests                                                           | Production graph/redeploy walkthrough NOT_RUN                         |
| Task/file/checklist text to AI planner   | Prompt injection, invented nested IDs, model-created authorization             | Stored text is untrusted; bounded allowlisted context, recursive ID/flag policy, server-owned previews, owner/actor-bound plans and canonical domain execution; independent injection/preview/readback/retry tests                               | Live model unavailable: EXTERNALLY_BLOCKED                            |

| Private calendar URL to outbound HTTP    | SSRF, DNS rebinding, redirect to metadata endpoint, oversized feed             | Exact HTTPS allowlist, all resolved addresses checked, connection pinned to public IP, zero redirects, bounded time/bytes/recurrence expansion; synthetic negative tests                                                                         | Actual deployed Google/iCal grant NOT_RUN                             |
| Google source to migration               | Lost attrs/IDs, false duplicate detection, invented graph, original moves      | Complete source snapshot/native-export comparison, actual original hashes/parents, immutable IDs/raw metadata, no graph inference, conflict quarantine; real source import/replay/restore rehearsal reconciles exact attrs                       | Fresh checkpoint and production cutover NOT_RUN                       |
| Backup to restore                        | Tampering, broken graph/history, old retry duplicating writes                  | Full owner-scoped relational checksums, AES-GCM/scrypt optional encryption, fresh isolated restore, accepted operation journal retained, replay-after-restore regression                                                                         | Hosted production restore and automated byte backup NOT_RUN           |
| Public Git/CI/logs to private material   | Credentials, source content, IDs, screenshots, feed URLs leaked                | Public synthetic fixtures only; private artifacts outside repository; sanitized counts/status in source CLI output; centrally owned public-safety scan                                                                                           | Final Git history/CI/production scan NOT_RUN                          |

Credential theft and workstation compromise are outside the protection of an authenticated app; rotate/revoke through the supported owner controls and preserve evidence. DPoP requests fail closed until shared replay protection exists. Google connector credentials are not copied into the app. No email, calendar-write, Drive-sharing or source-move permission is inferred from a task or its content.

## Independent defects found and repaired

- Scalar JSONB backup values caused restore errors; restore now serializes all JSON/JSONB types.
- Accepted idempotency operations were missing from backups; they are retained and a pre-backup retry after restore no longer duplicates a task.
- AI checklist/item read-back used a non-task entity ID; it now reads affected parent tasks.
- Nested prerequisite IDs/authorization flags escaped the initial model policy; recursive validation now rejects them.
- Blob namespace validation disagreed with actual uploaded keys; the shared owner-key validator is canonical.
- Direct upload registration could trust invented metadata; canonical registration verifies actual provider bytes.
- Google source archive/restore could change only SQL labels; unsupported provider execution now fails closed and preserves originals.
- An existing encrypted scheduled backup could be falsely verified without checking its table hashes; the job now uses the canonical format/schema/owner/table/manifest verifier and the independent regression passes.

The controls are independently tested at their appropriate layers. Do not mark a production release ready while a required external connection or deployment gate lacks evidence.
